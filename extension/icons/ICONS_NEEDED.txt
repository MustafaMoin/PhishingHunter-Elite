EXTENSION ICONS NEEDED
======================

You need to add the following icon files to this directory:

Required Files:
  - icon16.png   (16x16 pixels)
  - icon32.png   (32x32 pixels)
  - icon48.png   (48x48 pixels)
  - icon128.png  (128x128 pixels)

Icon Design Recommendations:
  - Use the PhishingHunter cyber-HUD color scheme:
    * Primary: #00ff88 (neon green)
    * Secondary: #00d4ff (cyan)
    * Background: #0a0e1a (dark)
  
  - Icon should be recognizable at small sizes
  - Consider using a shield or target symbol
  - Make it stand out in the toolbar

Creating Icons:
  1. Design at 128x128 (largest size)
  2. Export/resize to other sizes
  3. Use PNG format with transparency
  4. Name files exactly as shown above

Tools You Can Use:
  - Figma, Adobe Illustrator, Inkscape (vector design)
  - GIMP, Photoshop, Pixlr (raster design)
  - Icon generators: https://realfavicongenerator.net

Quick Option:
  - Use a simple emoji or symbol temporarily
  - Search "extension icon generator" online
  - Use AI image generators (DALL-E, Midjourney, etc.)

Placeholder:

  The extension will still work, it just won't look as polished.
