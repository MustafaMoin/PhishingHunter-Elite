API Configuration
ℹ️ About API Endpoint
The extension needs to connect to a PhishingHunter API server. By default, it connects to http://127.0.0.1:5000 (local server). You can change this to point to a remote server.
Enter the full API endpoint URL. Must include /api/check path.
Quick Start Guide

1. Start the PhishingHunter server:
Run python app.py in your PhishingHunter directory

2. Verify the server is running:
Open http://127.0.0.1:5000 in your browser

3. Browse normally:
The extension will automatically scan pages and show risk scores in the badge

4. Check results:
Click the extension icon to see detailed analysis, or right-click any link and select "Check this link with PhishingHunter"
