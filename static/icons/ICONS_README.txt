PWA ICONS NEEDED
================

For "Add to Home Screen" functionality, you need to create icon files in this directory.

Required Icon Sizes:
  - icon-72x72.png
  - icon-96x96.png
  - icon-128x128.png
  - icon-144x144.png
  - icon-152x152.png
  - icon-192x192.png   (minimum for PWA)
  - icon-384x384.png
  - icon-512x512.png   (minimum for PWA)

Icon Design Recommendations:
  - Use PhishingHunter color scheme:
    * Primary: #00ff88 (neon green)
    * Secondary: #00d4ff (cyan)
    * Background: #0a0e1a (dark) or transparent
  
  - Icon should work at small sizes (72x72)
  - Consider a shield, target, or hunter symbol
  - High contrast for visibility
  
Creating Icons:
  1. Design at 512x512 (largest size first)
  2. Export/resize to smaller sizes
  3. Use PNG format with transparency
  4. Name files exactly as shown above

Tools:
  - Online: https://realfavicongenerator.net
  - Design: Figma, Canva, Adobe Illustrator
  - AI: DALL-E, Midjourney (then resize)
  
Quick Option:
  - Use a simple solid color circle with a letter "P" or shield icon
  - Until you have proper icons, PWA will still work but won't look polished

Note: The app works without icons, but "Add to Home Screen" looks better with them.
